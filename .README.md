\# Laboratorio de replicación PostgreSQL



Proyecto práctico de alta disponibilidad orientado a configurar y documentar la replicación de una base de datos PostgreSQL entre dos máquinas virtuales.



\## Objetivo



Implementar replicación en streaming entre un servidor PostgreSQL principal y un servidor de respaldo, comprobar la sincronización de los datos y realizar un failover manual cuando el servidor principal deje de estar disponible.



\## Tecnologías



\* PostgreSQL 16

\* Ubuntu Server 24.04 LTS

\* VirtualBox

\* Git y GitHub

\* PowerShell y SSH



\## Arquitectura del laboratorio



| Máquina virtual | Función                         | Dirección IP    |

| --------------- | ------------------------------- | --------------- |

| `pg-primary`    | Servidor PostgreSQL principal   | `192.168.56.10` |

| `pg-standby`    | Servidor PostgreSQL de respaldo | `192.168.56.11` |



```mermaid

flowchart LR

&#x20;   A\["pg-primary<br>192.168.56.10"] -->|"Streaming replication"| B\["pg-standby<br>192.168.56.11"]

```



Los cambios realizados en `pg-primary` serán enviados continuamente a `pg-standby` mediante los registros WAL de PostgreSQL.



\## Actividades



\* Crear dos máquinas virtuales.

\* Instalar Ubuntu Server.

\* Configurar nombres de host y direcciones IP estáticas.

\* Instalar PostgreSQL en ambos servidores.

\* Configurar la replicación en streaming.

\* Insertar datos en el servidor principal.

\* Verificar que los datos lleguen al servidor de respaldo.

\* Simular la caída del servidor principal.

\* Promover el servidor de respaldo.

\* Medir el tiempo de recuperación.

\* Documentar los comandos, resultados y evidencias.
